# Kostas Vilkelis Portfolio

Static personal portfolio built with Astro.

## Requirements

- Node.js 22.12 or newer
- npm

## Install

```sh
npm install
```

## Develop

```sh
npm run dev
```

Astro will print the local development URL.

## Build

```sh
npm run build
```

The static site is generated in `dist/`. The `dist/` directory is ignored and should not be committed.

## Preview The Build

```sh
npm run preview
```

By default this serves the built site on `127.0.0.1`.
